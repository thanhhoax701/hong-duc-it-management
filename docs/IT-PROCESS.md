# Hồng Đức IT Management — Quy trình IT chuẩn hóa

## 1. Cấu trúc chính

1. PHẦN CỨNG
2. HỆ THỐNG
3. MÁY CHỦ

## 2. Phần cứng

- PC/Laptop
- Điện thoại
- Máy in
- TV/Máy chiếu
- Mạng cơ bản
- Rack
- Thiết bị

## 3. Hệ thống

- Tổng đài
- Camera
- UPS/Power
- Máy chấm công

## 4. Máy chủ

- Server
- Mạng
- Firewall
- Storage/Backup

## 5. Quy trình ticket

Tiếp nhận → Phân loại → Chọn danh mục → Kiểm tra hiện trạng → Phân công → Xử lý → Kiểm tra lại → Ghi nhận thay đổi → Hoàn tất.

## 6. Mỗi danh mục phải có

- Cơ bản
- Nâng cao
- Checklist
- SOP/Document
- Asset liên quan
- Ticket liên quan
- Change Log
- Lịch bảo trì
- File/hình ảnh đính kèm
- Người phụ trách

## 7. Chức năng nên bổ sung

- IP/MAC/Port Inventory
- Network Diagram
- Server Health
- Firewall Rule Register
- Backup Job/Restore Test
- Storage Health
- Camera/NVR Health
- UPS Battery/Load
- Phone/Extension Inventory
- Device Lifecycle
- SLA/KPI
- Audit Log
- Phân quyền IT Admin / IT Operator / Requester

## 8. Firebase

Giữ nguyên Firebase Authentication, Firestore realtime và Firebase Storage. Không thay đổi database hiện tại.
